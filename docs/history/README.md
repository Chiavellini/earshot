# docs/history — frozen historical evidence

Everything in this directory is frozen historical evidence: postmortems,
diagnoses (`casino143.md`), session handoffs, superseded runbooks and day
diaries, and archived slate deltas (`slate-changes/`). Nothing here is
operational procedure — do not run an event from these files.

Current authorities: `docs/STATUS.md` (state) and
`docs/runbooks/EVENT-LIFECYCLE.md` (the event procedure).
